Activity Loader

Four parts: Activity types, Curriculum books, Generate, then play in Loader.

An Activity is the game type — Jumping OX, Jeopardy, Vocab. The rules stay the same for every book. Only the words change later in Generate. You can also add a new activity style with AI from an HTML file or a short description.
